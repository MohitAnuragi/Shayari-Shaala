##  Overview

**Shayari Shaala** is a beautifully designed Android application that brings together  
**deep, emotional, funny, and modern Hindi Shayari & Quotes** in one place.

The app is built using **Kotlin + Jetpack Compose** with a strong focus on:
- Clean UI
- Smooth animations
- User-friendly reading experience

Available on **Google Play Store**  
 https://play.google.com/store/apps/details?id=com.shayarishaala.shayarishaala  

 Trusted by **1000+ users** and growing organically.

---

##  Features

- Multiple Shayari Categories:
  -  Love
  -  Friend
  -  Attitude
  -  Sad
  -  Funny
  -  Motivation
  -  Trending & Festival Shayari

-  Trending Shayari section
-  Like button with animation & counter
-  One-tap copy to clipboard
-  Easy share with friends
-  Modern Material 3 UI
-  Smooth splash & screen animations
-  Multi-language ready architecture
-  No login required (privacy friendly)

---

##  Tech Stack

- **Language:** Kotlin  
- **UI Toolkit:** Jetpack Compose  
- **Design System:** Material 3  
- **Navigation:** Navigation Compose  
- **Architecture:** State-driven Compose UI
